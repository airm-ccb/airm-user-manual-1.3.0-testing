# USING THE AIRM

## 🔍 AIRM Search

The `AIRM Search` provides online access to the latest version of the `AIRM`, the ATM reference vocabulary. 
The `AIRM Search` provides access to terms, definitions and abbreviations from ICAO documents (annexes, manuals, etc.) and more.

➡️ [`Go to AIRM Search`](https://airm.aero/dictionary/1.2.0/search) ⬅️

## 💻 AIRM API

Connect your software with the `AIRM API` to retrieve terms, definitions, URNs and much more. 

➡️ [`Go to AIRM API`](https://airm.aero/developers/api) ⬅️
