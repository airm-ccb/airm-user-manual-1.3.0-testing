# How to prepare and submit a Change Request

## Join the AIRM Community Area 

AIRM Change Requests (CRs) are submitted and managed through the AIRM Community Area, an online environment based on Microsoft SharePoint, hosted by EUROCONTROL and located at https://ost.eurocontrol.int/sites/airm 

It is required to join the AIRM Community Area to be able to create and submit an AIRM Change Request. 

Note: If you have already joined the AIRM Community Area, please skip this section and go to A.2 

To join the area, use a web browser to access the URL indicated above. Then select “New user” and follow the steps.
